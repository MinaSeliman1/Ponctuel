# Code de conduite

## Notre engagement

Ponctuel est un projet public d’apprentissage et de portfolio. Nous voulons
un espace accueillant, professionnel et respectueux pour toute personne qui
signale un problème, propose une amélioration ou contribue au code.

## Comportements attendus

- communiquer avec respect, patience et bonne foi;
- expliquer les décisions techniques avec des faits reproductibles;
- accueillir les désaccords sans attaque personnelle;
- protéger les informations privées et les secrets;
- privilégier des échanges accessibles et constructifs.

## Comportements inacceptables

Sont notamment inacceptables le harcèlement, les menaces, les propos
discriminatoires, les attaques personnelles, la publication d’informations
privées, le partage de secrets ou toute tentative de perturber volontairement
le projet et ses vérifications.

## Signalement

Pour signaler un comportement problématique, contacte le mainteneur via le
profil GitHub [MinaSeliman1](https://github.com/MinaSeliman1). Ne publie pas de
donnée personnelle ni de détail sensible dans une issue publique. Pour une
vulnérabilité technique, utilise le signalement privé de sécurité du dépôt et
consulte [SECURITY.md](SECURITY.md).

Le mainteneur examinera le signalement de manière confidentielle lorsque cela
est possible et pourra demander les informations minimales nécessaires pour
comprendre la situation. Les décisions d’application resteront proportionnées
aux faits observés et pourront inclure un avertissement, la modération d’un
échange ou la fermeture d’une contribution.

## Portée

Ce code de conduite s’applique aux issues, pull requests, revues de code,
discussions et autres espaces utilisés pour contribuer à Ponctuel.
